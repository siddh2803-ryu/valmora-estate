# Contributing to Valmora

Thank you for your interest in the Valmora Estate prototype!

## Project Nature
This repository is primarily maintained as a **design & engineering prototype showcase** for prospective clients looking to hire me for bespoke web and mobile application builds.

## Suggestions & Feedback
- If you notice a bug or UI issue on a specific device, feel free to open a [Bug Report](https://github.com/siddh2803-ryu/valmora-estate/issues/new?template=bug_report.md).
- If you have an idea for an interactive motion pattern, open a [Feature Request](https://github.com/siddh2803-ryu/valmora-estate/issues/new?template=feature_request.md).

## Hiring Inquiries
If you would like a custom digital experience or mobile application built for your own business, submit a [Client Project Inquiry](https://github.com/siddh2803-ryu/valmora-estate/issues/new?template=client_project_inquiry.md) or email [siddh2803@gmail.com](mailto:siddh2803@gmail.com).
