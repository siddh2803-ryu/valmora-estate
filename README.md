## 📌 About This Prototype

**Valmora** is an editorial, cinematic digital experience created as a **production-grade portfolio prototype**.

It was engineered from the ground up to demonstrate **high-end craftsmanship, bespoke motion design, and responsive mobile architecture** to prospective clients, founders, and teams looking to hire a dedicated developer for their next **website** or **mobile application**.

Instead of generic website templates, this build illustrates how thoughtful typography, physical inertia gestures, and smooth scroll synchronization can elevate a brand into an unforgettable digital atmosphere.

## ✨ Prototype Highlights & Technical Craft

| Feature | Technical Implementation |
| :--- | :--- |
| **Editorial Design System** | Bespoke typography pairing (*Fraunces* serif & *Archivo* grotesk) with an organic Mediterranean earth palette ([Design Tokens](docs/DESIGN_SYSTEM.md)). |
| **Kinetic Motion Pipeline** | 60/120fps synchronized motion combining **Lenis** smooth scrolling with **GSAP ScrollTrigger** depth-layered parallax and line-mask text reveals. |
| **Zero-Framework SPA Architecture** | Fluid, zero-refresh cross-fading routes (*Stay, Architecture & Craft, What's On, Villas to Rent, Contact, 404*) with zero heavy bundle bloat ([Architecture Details](docs/ARCHITECTURE.md)). |
| **Tactile Inertia Gestures** | Horizontal touch and drag galleries engineered with exponential velocity decay physics (`v *= 0.95`). |
| **Mobile App Companion Concept** | Specification and screen flow design for native iOS & Android companion app port ([Mobile Concept](docs/MOBILE_APP_CONCEPT.md)). |
| **Offline Resilience (PWA)** | Progressive Web App manifest and service worker caching strategy for rapid loading across slow mobile networks. |
| **Inclusive Design** | Comprehensive keyboard accessibility, focus trap modals, and instant graceful degradation when `prefers-reduced-motion` is detected. |

## 🛠️ Tech Stack

* **Frontend:** Semantic HTML5, Modern CSS3 custom properties, Vanilla JavaScript (ES6+)
* **Animation & Physics:** [GSAP 3](https://greensock.com/gsap/), [ScrollTrigger](https://greensock.com/scrolltrigger/), [Lenis Scroll](https://github.com/darkroomengineering/lenis)
* **Mobile & Offline:** Web App Manifest (`manifest.json`), Service Worker (`sw.js`)
* **Tooling & Runtime:** Node.js, NPM, GitHub Actions CI
* **Deployment & Edge CDN:** [Vercel](https://vercel.com)

## 💻 Local Development Setup

To run this prototype locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/siddh2803-ryu/valmora-estate.git

# 2. Enter directory
cd valmora-estate

# 3. Start local development server
npm start
```

Open your browser to `http://localhost:4173`.
