# Valmora — A Private Estate in the Douro Hills

An editorial, cinematic web experience for Valmora Estate featuring smooth animations, interactive transitions, and responsive design.

## Features

- **Editorial Design System**: Custom typography pairing (*Fraunces* serif & *Archivo* grotesk) and earthen palette.
- **Smooth Scrolling & GSAP Animations**: Powered by Lenis, GSAP, and ScrollTrigger for immersive parallax and reveals.
- **Multi-page SPA Flow**: Dynamic transitions across *Stay, Architecture & Craft, What's On, Villas to Rent, Contact, and 404*.
- **Interactive Modules**: Drag galleries, sound toggles, booking & newsletter overlays.

## Quick Start

### Local Development
```bash
npm start
```
Or open `index.html` directly in your browser.

## Deployment

Deployable instantly on **Vercel**, **GitHub Pages**, **Netlify**, or any static site host.
